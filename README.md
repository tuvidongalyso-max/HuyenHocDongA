# Khổng Minh Thần Toán – Huyền Học Đông A

Web tĩnh gieo quẻ và tra cứu 384 quẻ Khổng Minh. Một file `index.html` duy nhất, không cần build.

Liên hệ: 079 43 53 630 (Master Trần Đức Trường).

## Đưa lên GitHub Pages
1. Tạo repository mới, tải `index.html`, `.nojekyll` và `README.md` lên nhánh `main`.
2. Vào Settings > Pages, chọn Source: Deploy from a branch, Branch: `main`, thư mục `/ (root)`, bấm Save.
3. Sau khoảng 1 phút, web chạy tại `https://<tên-tài-khoản>.github.io/<tên-repo>/`.

Ghi chú: font chữ tải từ Google Fonts nên cần có mạng. Lịch sử gieo quẻ lưu trong trình duyệt của từng người dùng.
