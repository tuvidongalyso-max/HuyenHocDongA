Thêm vào màn hình chính iPhone: mở link bằng Safari, bấm nút Chia sẻ, chọn "Thêm vào Màn hình chính".

## Xem thống kê truy cập hằng ngày (GoatCounter, miễn phí)
1. Vào https://www.goatcounter.com , bấm Sign up, đặt "Code" (ví dụ `huyenhocdonga`), điền địa chỉ web của bạn ở ô Domain.
2. Trên GitHub, mở file `config.js`, sửa `window.GC_CODE = "";` thành `window.GC_CODE = "huyenhocdonga";` (đúng mã bạn đặt), bấm Commit.
3. Xem tại https://huyenhocdonga.goatcounter.com : lượt xem theo ngày, số người truy cập, thiết bị, quốc gia, nguồn truy cập.
   Mục "Events" cho biết số lượt gieo quẻ, quẻ nào được gieo, xem Chú giải / Luận theo việc, lưu PDF, sao chép kết quả, bấm gọi.
